# 智能分诊系统 - 使用说明

## 🚀 快速启动（推荐）

### 方法 1：使用 VBScript（完全隐藏窗口）
双击 `智能分诊系统.vbs`
- ✅ 不显示终端窗口
- ✅ 自动打开浏览器

### 方法 2：使用 Python 启动器
双击 `快速启动.bat`
- ✅ 显示一个小窗口显示状态
- ✅ 按 Ctrl+C 停止服务

### 方法 3：传统方式
双击 `启动服务.bat`
- ✅ 显示两个终端窗口
- ✅ 手动关闭窗口停止服务

## 📋 文件说明

| 文件名 | 说明 |
|--------|------|
| `智能分诊系统.vbs` | 完全隐藏终端的启动器（推荐） |
| `快速启动.bat` | 简单启动器，显示运行状态 |
| `启动服务.bat` | 传统方式，两个终端窗口 |
| `app_launcher.py` | Python 启动器代码 |
| `main.py` | API 服务（端口 8012） |
| `webUI.py` | Web UI（端口 7860） |

## 🎯 创建桌面快捷方式

1. 右键点击 `智能分诊系统.vbs`
2. 选择「发送到」→「桌面快捷方式」
3. 可以右键快捷方式 → 「属性」→ 「更改图标」自定义图标

## 🛑 停止服务

### 方法 1（VBScript）
- 打开任务管理器
- 找到 `python.exe` 进程（两个）
- 右键结束任务

### 方法 2（快速启动.bat）
- 在窗口中按 `Ctrl+C`

### 方法 3（启动服务.bat）
- 直接关闭两个终端窗口

## 🌐 访问地址

- **Web UI**: http://localhost:7860
- **API**: http://localhost:8012

## 📝 注意事项

- 确保端口 7860 和 8012 没有被占用
- 首次启动需要等待约 10-15 秒
- 关闭窗口或进程即可停止服务
